# mcli-launcher

基于REPL的mc launcher（仅支持正版登录）：原版 / Forge / NeoForge / Fabric 下载安装、
整合包安装（Modrinth / CurseForge / MultiMC）、隔离所有版本，与plc2的版本隔离模式完全兼容，可直接套用。
不支持直接下载mod
<br>

纯搞怪项目，可作为客户端下载的下位替代，
当然，欢迎喜欢命令行操作的人员来赤石

## 运行

```
launch.bat
```

要求 Java 21+。help查看所有指令

```
<rootDir>/mcli/mcli-launcher.jar   <rootDir>/mcli/launcher.toml   <rootDir>/mcli/data/
<rootDir>/.minecraft   <rootDir>/log/
```

## 说明
- 仅支持正版账号登录
- 默认禁止多人游戏
- 所有的内置付费本启动器一律视为诈骗，一切后果自行承担
